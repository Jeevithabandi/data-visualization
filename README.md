# Data Visualization

My homework and worksheets from DATA 5310 Data Visualization, Seattle
University, Fall 2025. All my own work.

## What this is

Homework and in-class worksheets on data visualization, in R (tidyverse,
ggplot2) and Python (Altair). The work covers encodings and marks, data
transformation, composition, maps with GeoPandas, and cleaning text, plus
homework assignments — including one that visualizes Seattle Police Department
crime data.

- `homework/` — Homework 1 (R), a short reflection on Homework 1, Homework 3,
  and Homework 6 (Python/Altair notebooks, rendered as HTML)
- `worksheets/` — weekly worksheets and in-class work

## What is not here

  fixing low contrast, truncated labels, and missing values — using Seattle
  crime data, with a monthly crime-counts chart and a top-12-neighborhoods
  chart. I recorded a short walkthrough of it, about two and a half minutes
  of me presenting in Canvas and a browser. The rendered homework file is
  about 155 MB, which GitHub won't take, and the recording shows my laptop's
  file paths on screen, so neither of them is here.
- **Homework 4** is out for the same reason — the rendered file is about
  155 MB and it embeds the full crime dataset.
- **Homework 6 is not in this repo as a file.** The rendered HTML is 77 MB
  with embedded plots, and GitHub's upload API won't take a file that big —
  it has to be added with a normal `git push` from a local copy instead. The
  homework is described here: an Altair notebook on the course data, rendered
  with all its charts embedded. To add the file, clone this repo and push the
  `Homework6_jeevitha.html` file from your own machine — it fits under
  GitHub's 100 MB per-file limit for a regular push.
- **The final project is not here.** My final-project group work was not among

  worksheets. My peer evaluation of the final project names my group members
